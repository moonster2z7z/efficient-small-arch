# efficient-small-arch

대형 데이터·대형 GPU로 키우는 트랜스포머와 다른 방향에서, 적은 데이터·연산·전력으로 학습하고 추론하는 작은 구조를 찾는 연구 저장소.

- 판정: `python bench.py` 한 번 실행 (고정 벤치 묶음, 같은 파라미터·연산 예산의 트랜스포머 기준선과 비교, 시드 3개, 데이터 1/10 조건 포함)
- 제약: 사전학습 가중치 없음, 평가 데이터로 학습하지 않음, 모든 코드·로그·실패 기록 보존
- 진행 기록: `EXPERIMENTS.md` (시도와 폐기 이유), `logs/` (원본 로그)

작업 진행 중. 구조와 결과는 계속 갱신됨.
